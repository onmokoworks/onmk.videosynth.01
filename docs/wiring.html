Vs-01 配線図

2026-10-27 版（v2：Codex の監査を反映）。箱ごとにマイコンを入れて、DATA ケーブル（3.5mm ステレオ）で値をメインに集め、Pi Zero v1.3 が GLSL で映像を作る構成。

[フェーダー箱] Pico ＋ 74HC4067 ノブ4・フェーダー5 │ DATA 1 ケーブル：先端 = 信号（箱 → メイン）／中間 = 5V（メイン → 箱）／根元 = GND [キー箱] RP2350-PiZero キー8・TAP4（全部ボタンなのでアナログ入力はいらない） │ DATA 3 ケーブル：同じ [メイン] Pico ノブ2・GOOD KNOB（エンコーダー）・RESET ＋ 横の箱の値をまとめる │ UART（TX と GND の2本） [メイン] Pi Zero v1.3 シェーダー → HDMI、小さい液晶（TFT）も Pi Zero が表示 [メイン] USB-C 電源入口 → POWER トグル → 5V（全部に配る）
3.3V5VGNDアナログ（ノブ・フェーダー）デジタル（キー・エンコーダー・切り替え）シリアル（UART）・液晶

図の中の 3V3 / 5V / GND の小さな札は「同じ名前の札どうしは全部つながっている」という意味（線を全部描くと見づらいので省略）。

守ること（これだけ）
  • 電源を入れたまま DATA ケーブルを抜き挿ししない。挿す瞬間に 5V が信号線に触れてマイコンを壊すことがある。展示中はケーブルをテープで固定する。
  • ノブ・フェーダーの端は 3.3V につなぐ（5V はだめ）。
  • 横の箱は、DATA の 5V → ショットキーダイオード → 電源入力。帯のある側を基板側に。USB を挿したまま動かしても逆流しない。
  • DATA の信号線（先端）には、箱側とメイン側の両方に 1kΩ を入れる（念のための保護）。
  • 箱の柱に載せて端子を壁の穴に合わせるのは Pi Zero。メインの Pico は箱の中の空いた所に両面テープで固定。
  • Pi Zero は電源を急に切られても壊れないよう読み込み専用にする（再生プログラムを入れるときに設定）。

2. キー箱（RP2350-PiZero）

GP 番号は RP2350 のピン番号。40ピンの物理番号や Pi の GPIO 番号とは別物なので、基板の印刷（GP○○）を見てつなぐ。

キー・TAP

部品RP2350-PiZero
キー 0〜3（上の段、左から）GP2 / GP3 / GP4 / GP5
キー 4〜7（下の段、左から）GP6 / GP7 / GP8 / GP9
TAP 0〜3（左から）GP10 / GP11 / GP12 / GP13

スイッチの片足 → GP、もう片足 → GND。抵抗はいらない（内蔵のプルアップを使う）。基板にその GP が出ていなければ、空いている別の GP に変えて教えてください（プログラム側で合わせます）。

5V 2A 以上の USB 充電器。電源の入口のそばに 10〜47µF のコンデンサがあると安定する。
Pi Zero を 5V ピンから給電している間は、Pi Zero の micro USB には何も挿さない。

4. 送るデータの形（プログラム用）

どこ → どこ形頻度
フェーダー箱 → メインF,k2,k3,k4,k5,f0,f1,f2,f3,f4\n（0〜4095、ノブは全体の番号 2〜5）50 回/秒
キー箱 → メインK,kkkkkkkk,tttt\n（押している所が 1）変化したとき＋10 回/秒
メイン Pico → Pi ZeroV,k0..k5,f0..f4,keys,taps,enc,reset\n（ノブ・フェーダーは 0〜1、enc は回した段数の合計。u_good = enc/24）60 回/秒

どれも 115200bps・8N1。Pi Zero v1.3 の GPIO15 は本物の UART（ttyAMA0）：enable_uart=1、シリアルコンソールは切る。

読み取りのコツ（プログラム側）：74HC4067 は切り替えて 20µs 待ち、1回捨ててから数回平均。エンコーダーは A/B の状態変化で数える。
